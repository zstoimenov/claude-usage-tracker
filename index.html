Free pass
A reset Anthropic sometimes gives that sets weekly and session usage to 0. Add it with its expiry and the app plans the best week and time to use it. The weekly reset day does not change.
Sync between devices
Keeps your sessions and weekly % in step across devices. No account needed: a private sync code links them. Data is encrypted on your device with a key derived from the code, so the server only stores scrambled data. Anyone with the code can see and change it, so only share it with your own devices.

To add another device, open the app there, go to Settings and paste the code. On iPhone, the home-screen app keeps its own storage apart from Safari, so paste the code into the installed app. Opening a link or QR code only links Safari.
Backup
